Bro, **this repo is much more useful than just a list of APIs**.

I checked the current repository. It is a huge community-maintained catalog of public APIs, with roughly **469K GitHub stars, 51K forks, and 5,000+ commits** as of now. The catalog is organized by dozens of categories and each API entry contains metadata such as description, authentication, HTTPS and CORS support. ([GitHub][1])

The important part is: **we should NOT just clone it and make another API-list website.** We can build something on top of it.

## 🔥 My top idea for you: "APIHub" / "API Explorer"

> **npm + Postman + RapidAPI-style discovery, but specifically for public/free APIs.**
